# Reven Pharmaceuticals

> Privately held, clinical-stage biopharmaceutical company founded in 1999 and headquartered in
> Broomfield, Colorado. Reven develops medicines from its proprietary RJX Technology platform - a
> patented, first-in-class intravenous composition of anti-oxidant and anti-inflammatory ingredients -
> with programs in sepsis, multi-system inflammation, cytokine release syndrome, ARDS, and vascular,
> oncology, CNS and ocular indications. Lead candidate Rejuveinix (RJX) completed a double-blind,
> placebo-controlled Phase 1 dose-escalation study in healthy volunteers and received FDA clearance of an
> Investigational New Drug application for the treatment of COVID-19.

## API surface

Reven Pharmaceuticals publishes **no public API**. As of 2026-08-26 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/gRPC/WSDL contract, no SDK or client package in any public
registry, no MCP server, and no A2A agent card. Every canonical discovery path on reven.com
(/openapi.json, /swagger.json, /api-docs, /graphql, /llms.txt, and the /.well-known/ set) returns 404.

The only machine-readable endpoint on the domain is https://reven.com/wp-json/, the default WordPress
REST API exposed by the corporate website's CMS. Its 228 routes are entirely WordPress core plus
installed plugins (Yoast, Elementor, Wordfence, LiteSpeed, Akismet, Formidable); it describes the
marketing site's content, not a Reven product, and is not treated here as a published company API.
